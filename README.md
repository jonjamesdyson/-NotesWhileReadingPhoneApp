# Nook 📖

**Nook** is a mobile application designed to help you organize/manage notes while reading and track your reading progress.

> 🤖 **Note:** This application was generated using **Google AI Studio** and is automatically built and published directly from this repository.

---

## 📥 How to Install Nook on Your Android Device

If you have never installed an app outside of the Google Play Store before, follow these simple steps to download and run Nook on your Android phone.

### Step 1: Download the App
1. Open this repository on your Android phone's web browser.
2. Scroll to the **Releases** section on the right side of the page (or scroll down on mobile) and tap on **Latest App Build**.
3. Under **Assets**, tap **`Nook.apk`** to start downloading the file.

---

### Step 2: Enable "Install Unknown Apps" Settings

Because Nook is downloaded directly from GitHub rather than the Google Play Store, Android marks it as coming from an "untrusted developer" or "unknown source." You will need to allow your device to install it.

1. Open your phone's **Settings** app.
2. Go to **Apps** (or **Apps & Notifications**).
3. Tap **Special app access** (or search for *"Install unknown apps"* in the settings search bar).
4. Tap **Install unknown apps**.
5. Select the app you used to download the file (e.g., **Chrome**, **Firefox**, or **My Files** / **File Manager**).
6. Toggle on **Allow from this source**.

> 💡 *Tip: On newer Android versions, if you simply tap the downloaded `Nook.apk` file, your phone will automatically display a security prompt with a direct button to **Settings** where you can enable this permission instantly.*

---

### Step 3: Install and Run Nook
1. Open your phone's **Downloads** folder or tap the completed download notification.
2. Tap **`Nook.apk`**.
3. Tap **Install** when prompted.
4. Once the installation is finished, tap **Open** or launch **Nook** directly from your home screen or app drawer!

---

## ⚙️ How It Works (For Developers)

This repository hosts native Android Kotlin code. Every time updates are committed to the code repository, a automated **GitHub Action** workflow automatically compiles the source code using Gradle, signs the package, and publishes the ready-to-install `Nook.apk` straight to the Releases section.
